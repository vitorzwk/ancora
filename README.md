# Âncora 🌱
Aplicação web para monitoramento de hábitos, com design acolhedor e foco em bem-estar emocional. O Âncora ajuda você a construir e manter hábitos saudáveis, acompanhar seu progresso diário e oferece um modo de emergência para momentos de recaída.

🔗 Acesse: ancora-olive.vercel.app

# ✨ Funcionalidades
Registro diário de hábitos — marque o que você cumpriu ao longo do dia.

Visualização de progresso — acompanhe sua evolução e consistência.

Modo de emergência — apoio para recaídas, com acolhimento em vez de culpa.

Design acolhedor — interface leve e pensada para reduzir a ansiedade.

# 🛠️ Stack
React

TypeScript

Vite (build e dev server)

Vercel (deploy)

# 🚀 Rodando localmente
```

# Clone o repositório
git clone https://github.com/vitorzwk/ancora.git

# Entre na pasta
cd ancora

# Instale as dependências
npm install

# Rode em modo desenvolvimento
npm run dev
```

# 📦 Build para produção
```
npm run build
npm run preview
```
# 🌐 Deploy
O projeto está hospedado na Vercel: ancora-olive.vercel.app

# 🎯 Sobre o projeto
O Âncora nasceu da ideia de que construir hábitos não precisa ser uma experiência punitiva. Em vez de focar apenas em “não falhar”, o app valoriza o processo, o registro diário e o cuidado com você mesmo — inclusive nos dias difíceis.
